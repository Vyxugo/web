inti (inkaverse)

Flavio Lozano-Isla 2026 included in projects

🎯 Objetivo

inti es el paquete de R central del proyecto inkaverse, un conjunto de herramientas y flujos de trabajo para ciencias de plantas: diseño experimental, análisis de datos y redacción científica. Es la base sobre la que construimos Huito y tocapu para el etiquetado, y lo uso en mi día a día de investigación para pasar de la planificación en campo a resultados analizados sin cambiar de herramienta.

🛠️ Herramientas

  • R (paquete disponible en CRAN)
  • Shiny — apps Tarpuy y Yupana
  • pak / GitHub para versiones de desarrollo

⚙️ Instalación

Versión estable desde CRAN: 

install.packages("inti")

Versión de desarrollo desde GitHub, usando pak: 

if (!requireNamespace("pak", quietly = TRUE)) {
  install.packages("pak")
}

pak::pkg_install("flavjack/inti")

📌 Las dos apps de Shiny

Tarpuy es la plataforma para planificar experimentos, generar el fieldbook, organizar tratamientos y gestionar la colecta de datos: 

inti:::tarpuy_full()

Yupana es el entorno para el análisis estadístico y la visualización de los datos experimentales: 

inti:::yupana_full()

Ambas se pueden abrir desde el menú de Addins de RStudio o directamente desde la consola de R.

✅ Resultado

Un flujo continuo que va desde el diseño del experimento y la colecta de datos en campo (Tarpuy), pasando por el análisis estadístico (Yupana), hasta la preparación de resultados para publicación — todo dentro del mismo ecosistema de R.
